## v1.1.3 (2026-08-30)
- Ignore privatekey/publickey (ser2net/TLS credentials) so they no longer show up as local changes
- Fix Update refusing to apply whenever any untracked file (e.g. a stray web/app.py.bak) was present in the checkout: only a locally modified *tracked* file outside the known runtime-state files now blocks an update; untracked clutter is left alone since it can't conflict with a fast-forward pull

## v1.1.2 (2026-08-30)
- Update tab now shows the current version immediately on open (via a new local-only /update/current check, no GitHub call), instead of only after clicking Check for Update
- Render the changelog for an available update as formatted headings and bullet lists per version instead of a raw text block

## v1.1.1 (2026-08-30)
- Fix Update tab always refusing to apply an update ("Repository has local changes") because the app's own runtime state files (web/config.json, audio/audio_config.cfg, web/trx_config.json, web/band_rules.json) were tracked or untracked-but-not-ignored, so git always saw them as locally modified. They're now gitignored, and the update flow preserves their live content across a git pull

## v1.1.0 (2026-08-30)
- Consolidate the web panel from 8 tabs to 6: Band Relay rules moved into the TRX tab, Audio Stream Settings and the Restart Audio Services button moved into the Audio tab, the Status tab merged into Config as a "Network Status" section, and the Restart Web Panel button moved into the Update tab

## v1.0.0 (2026-08-30)
- Add Update tab to the web panel: checks GitHub for a newer release tag, shows the changelog for it, and applies the update (git pull + restart of all related systemd services) with one click
- Fix Audio tab volume settings not persisting across reboot (alsactl store lacked permission when the panel runs as the "pi" user)
