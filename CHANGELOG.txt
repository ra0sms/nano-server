## v1.2.1 (2026-09-09)
- Group-scoped automatic relay switching: if the band rules only use relays 1-8 (or only 9-16), the other group is left untouched, so those relays can still be selected manually and their state survives every frequency change
- Live web UI updates via Server-Sent Events (`/events`) replace the per-tab 2 s HTTP polling; a persistent status bar (PTT / TRX / client RTT) is now shown on every tab
- Removed the fixed `/dev/ttyCAT` binding: the CAT serial port is chosen on the web Settings tab, and `fix_usb_ports.sh` is no longer used
- Web panel no longer crashes when the I2C relay module is absent: the I2C bus and both expander addresses are probed safely at startup and every relay write is guarded
- Fix TRX showing ONLINE when no transceiver is attached: `online` now reflects an actual CAT response (with a 5 s inactivity timeout) instead of merely an opened serial port

## v1.1.5 (2026-08-30)
- Fix the actual cause of the broken web panel (a bug present since v1.1.2, not v1.1.3 as first suspected): the changelog-rendering JS had literal "\n" sequences written inside app.py's non-raw triple-quoted HTML_TEMPLATE string, so Python's own string parsing turned them into real newline characters before they ever reached the browser, corrupting a JS comment and splitting a string literal across lines ("Uncaught SyntaxError: string literal contains an unescaped line break"), which broke every tab and button on the page. All such sequences are now properly double-escaped
